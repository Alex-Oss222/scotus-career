# Stone planning files

Files in this directory are planning and research aids. They are not entering law, do not establish another Justice's position, and do not fill a missing Stone choice. A case-specific Stone position controls only when it is carried into the approved case material used by the Engine.

| File | Status | Use |
|---|---|---|
| `Justice_Stone_OT1993_Research_and_Analysis.md` | Live OT1993 research aid | May inform drafting of Stone's case-specific position; not law. |
| `STONE_COMMERCE_CLAUSE_AND_FEDERALISM.md` | Live roadmap | Planning source for Stone's method in the covered line; not law. |
| `STONE_OPTION_C_FULL_BUILD_THROUGH_OT2001.md` | Long-range roadmap | Planning only; no case outcome enters from this file by itself. |
| `STONE_SHAW_RACIAL_GERRYMANDERING_LINE.md` | Live doctrinal roadmap | Planning and consequence-screening aid; not entering law. |
| `Second_Amendment.md` | Legacy pre-reboot build | Reference only; it does not establish current law in this timeline. |
| `Second_Amendment.txt` | Legacy duplicate | Reference only; prefer the Markdown file when historical comparison is needed. |

Planning labels such as “essential,” “optional,” “default-skip,” and “roadmap” stay in this directory and never migrate into Records, registers, or public renders.
