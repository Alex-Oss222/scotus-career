# Case 69 neutral source refresh

Read with the approved neutral packet and CASE69 entering law. This is additional record material, not an outcome or judicial position. The original modeling freeze is retained; this refresh requires fresh affected modeling.

The six Fleet Rules have commercial-availability qualifications. The relevant provisions are Rule 1186.1(e), Rule 1191(f)(8), Rule 1192(e)(2), Rule 1193(e)(3), Rule 1194(e)(2) and Rule 1196(e)(1)(C). The last provision permits an exemption when a compliant engine is unavailable from any manufacturer or cannot serve the particular application. Full exact provision coverage should be verified in the Joint Appendix where accessible before extending this formulation to each rule. This is decision-material to the argument that a purchase mandate selects available products rather than compelling production.

A published primary recitation establishes that the respondents did not defend these Fleet Rules as authorized by section 246 and that the Rules did not meet all that program's requirements. Section 246 remains statutory context for interpreting section 209, but not an independently live basis for upholding these particular Rules. No unverified oral-argument concession is used. Other supplied preserved issues concerning genuine public procurement, new versus used vehicles and any actually applicable waiver retain their stated scope.
