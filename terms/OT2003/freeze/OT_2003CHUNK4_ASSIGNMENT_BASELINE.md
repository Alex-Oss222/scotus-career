# OT2003 chunk 4 assignment baseline

Internal pre-assembly navigation and accounting aid. Records control. This baseline chooses no new author and revises no existing assignment.

## Scope and method

The audit applied [Engine section 8](../../../foundation/ENGINE.md#8-conference-assignment-circulation-and-final-joins). It mechanically extracted each existing OT2003 Record's case identity and event date, then inspected only the selected form/assignment sections and opinion tables or Opinion Topology. Authors were taken from each Record's actual lead-opinion attribution, not earlier assignment tallies. Each Justice delivering any part of a signed lead receives one count per opinion; partial lead authorship does not receive a fractional count. Signed leads following plenary review or full merits submission, including grants arising in this timeline, count. Per curiam opinions, summary dispositions, procedural actions and separate writings do not count.

Two accounting scopes are displayed explicitly. The ordinary Engine date-filtered inventory includes every existing Record effective on or before 2004-03-08. The operator's task-specific instruction instead counts the signed leads of all previously durable Records, including later-dated existing events, for assignment accounting only. Under that instruction the operative baseline is the all-durable table below. Before every new assignment assembly must recount from the actual opinion tables of all previously durable Records and Records written earlier in this Run, taking same-date new events in alphabetical case-name order. Later-dated law remains excluded from earlier merits modeling. Existing assignments remain unchanged; prior assignment tallies are not copied as evidence.
