# Terms

One folder per October Term. Before a term, you supply two things:

- `case-list.md` — the inventory of every case and Court action planned for the term, including any lower-court case you are adding with your fourth vote.
- `briefs/OT_<year>CHUNK<n>.md` — the case briefs, about ten cases per chunk, in the three-section form of `foundation/CASE_BRIEF_TEMPLATE.md`. If you split a chunk into `_NEUTRAL` / `_STONE` / `_COMPARATOR` files, they go in `runtime/`.

Everything else in the folder (`workspace.md`, `records/`, `output/`, `close/`) is written by Codex and should not be edited by hand.
