# Case library — isolated rebuild

This source library links canonical simulation Records and the historical references they actually cite. It is being rebuilt through OT1995 after the original uncommitted development workspace became unavailable. The rebuild uses new path-based Record identities; it does not claim to restore the original case IDs or reviewed mappings.

Production integration is disabled. Court commands and authoritative files are unchanged. Full Record links contain mixed public and internal material; this catalogue is not input to a restricted adjudication stage.

The implementation and validation status are recorded in STATUS.md. Recovered older material will be preserved under recovery/ with its provenance and missing dependencies. The old test results do not certify this rebuild.
